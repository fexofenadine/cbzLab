      Why is cbzLite limited?

      cbzLite is the cbzLab editor running as a web page: nothing to install, and your comics never leave your computer. A web page is kept on a much shorter leash than an installed app, though, so a few things only the cbzLab desktop app can do.

      Saving

      Chrome and Edge let a page write back to a file you opened, after asking you once. Firefox and Safari don't, so there an edited book is saved as a download and the original is left as it was. The desktop app always saves in place.

      CBR files

      CBR archives are RAR files, and browsers have no way to read or write RAR. The desktop app opens and saves CBR, and can convert it to CBZ.

      Finding your files again

      A page only ever sees the files you pick or drop, never their location on disk. So there's no Open Recent, no Open Containing Folder, and Guess from Filename only knows a book's folder if you opened it with Open Folder. Reopen Last Closed File works for files closed since the page was loaded.

      ComicVine lookups

      cbzLite makes no network requests at all, so it can't look books up on ComicVine. The desktop app does, with your own ComicVine API key.

      Combine Archives and Trim Branding Footers

      These are the heavy jobs: reading several whole books and writing a new one, or decoding and re-encoding page images. They're left to the desktop app so this page stays quick and light.

      Settings and safety nets

      Preferences are kept in this browser only, so clearing its site data resets them, and there's no settings backup. The desktop app also autosaves unsaved edits and offers them back after a crash; here, edits live in the page until you save, and the browser warns you before you leave with unsaved changes.

      Shortcuts

      Browsers keep Ctrl+W and Ctrl+Shift+T for their own tabs, so Close and Reopen Last Closed File are menu-only here.

      Settings

      DESKTOP APP ONLY

      These settings exist in the cbzLab desktop app but can't work in a browser:

      • Default save format, RAR write tool - browsers can't read or write RAR, so cbzLite always saves CBZ.
      • Confirm before batch save - it picks a format per file, and there's only one here.
      • Max recent files - a page can't reopen a file by its path, so there's no Open Recent.
      • Online lookup (ComicVine) - cbzLite makes no network requests at all.
      • Updates, config/themes/logs folders, settings backup - this page updates itself when reloaded, and keeps its settings in your browser rather than a folder.
